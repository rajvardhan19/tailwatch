# Deterministic feature runs

C15–C18 expose pure, versioned computations and atomic PostgreSQL publication. These are research signals, not deal probabilities. `Signal` permits a number only for observed inputs; missing, stale, ambiguous and insufficient-history inputs remain null.

Travel inputs must originate in completed C14 visits mapped through C11 approved control and C12 host attribution. `flight_signals` uses the declared complete observation interval; do not supply a broad interval over known gaps. Dwell ramps from zero at one hour to one at four hours, arrival decay is 14 days, current window is 30 days, novelty checks 365 days before the newest current episode excluding itself, and intensity uses twelve previous 30-day windows (390 days total). Zero baseline variance is unavailable. Multi-host episode IDs count once for visitor intensity.

`buying` accepts only C07-reviewed eligible purchases mapped to stable natural-person IDs and dated roles. It deduplicates economic IDs and person/event-date episodes, with a frozen 90-day computation window, 30-day decay, and a 1.5 multiplier for at least three buyers in 14 days. Unknown roles remain ambiguous. The 90-day window is an explicit research configuration choice, not a fitted predictive claim. `silence` consumes C09 blackout-adjusted covered exposure counts and C07-reviewed sale-day counts; it uses the fixed baseline-eligible insider denominator and a supplied observation watermark. At least four baseline sale days are required. The caller must establish 365-day baseline/45-day recent windows, tenure, holdings and disclosure latency; count-model sensitivity and unknown blackout policy must be reported. C08 already supplies quarter-scoped termination signal age and unknown/stale states.

Text inputs are cached permitted embeddings with document/chunk IDs, revision, publication/availability/expiry and evidence. Chunks average within documents, documents have equal weight, then means are normalized and cosine transformed to [0,1]. No model API is called. Version/dimension conflicts and zero vectors are unavailable. Financial inputs are point-in-time revisions, normalized security aggregates and currencies; invalid denominators and mixed currency are unavailable. Neither ratios nor semantic similarity establish acquisition direction.

`FeatureRun` freezes the full eligible universe, both directional hypotheses, exact input fact IDs and source snapshots, cutoff, code/config versions, required features and synthetic flag. Missing required features leave a pair unscorable. Interaction is multiplication only when both flight and silence are observed; downstream models may assign either sign. Canonical export and hash are deterministic. `publish_feature_run` checks every input was visible in its frozen source snapshot and publishes the entire run as one immutable fact in a caller-owned transaction. Begin the output snapshot with expected_records=1. A run cannot expose a partial vector or silently acquire concurrently published evidence. Real G2 coverage/provenance validation remains pending until real sources are assembled.
